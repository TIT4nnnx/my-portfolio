# My Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- ✨ Modern design with gradient backgrounds
- 📱 Fully responsive on all devices
- 🎯 Smooth scrolling navigation
- 🎨 Beautiful animations and transitions
- 📧 Contact form
- 🏆 Showcase your projects and skills

## Folder Structure

```
my-portfolio/
├── index.html          # Main HTML file
├── css/
│   └── style.css      # All styling
├── js/
│   └── script.js      # Interactive features
├── assets/
│   └── images/        # Place your images here
└── README.md          # This file
```

## Customization

1. **Personal Info:** Edit the name, title, and contact details in `index.html`
2. **Colors:** Change the color values in the `:root` section of `css/style.css`
3. **Content:** Add your own projects, skills, and about information
4. **Images:** Add your profile photo and project images to `assets/images/`

## Getting Started

1. Replace placeholder content with your own information
2. Add your images to the `assets/images/` folder
3. Update contact information with your actual details
4. Open `index.html` in your browser

## Browser Support

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.

Enjoy your portfolio!
